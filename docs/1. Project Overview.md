# Project Overview

## Design and Implement a CI/CD pipeline using GitHub Actions

You've been brought on as the DevOps resource for a development team that manages a web application that is a catalog of Movie Picture movies. GitHub Actions will be used to accelerate their release cycle.

## Your Tasks

1. Review the team’s existing local build process for the frontend and backend applications
2. Create a GitHub Action workflow that performs the necessary Continuous Integration steps on the frontend and backend applications:
   - lint
   - build
   - test
3. Create or enhance the workflow so that the pipeline deploys the frontend and backend apps to an existing Kubernetes cluster.
4. Verify deployment with the expected results displayed on the frontend

## Project Requirements

The pipeline will automate the testing, building, and deployment process for a provided backend and frontend application, you will need to :

- Define the steps for the pipeline and create the necessary workflows in GitHub Actions.
- Configure the pipeline to trigger on specific events, such as code pushes to the repository or pull requests.
- Define the necessary jobs and steps for each workflow, including:
  - running unit tests,
  - building the application, and
  - deploying to a staging environment
- Implement error handling and notifications to catch and report any failures or errors.
- Test and make any necessary adjustments to meet the project requirements.
- The result will be a fully automated CI/CD pipeline that streamlines the development process and improves the efficiency and reliability of a software application.
